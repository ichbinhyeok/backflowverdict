# BackflowPath 파트너 배포 플레이북

목표는 파트너에게 설명을 길게 하는 것이 아니라, 파트너가 고객에게 바로 보낼 수 있는 한 줄과 링크를 제공하는 것이다.

## 1. 파트너가 실제로 하는 일

1. `/partners/notice-kit`을 연다.
2. 자신의 표시 이름이나 짧은 코드(예: `dallas-testers`)를 입력한다.
3. 고객이 보낸 공지 단서(예: `Dallas SwiftComply annual notice`)를 입력한다.
4. 생성된 메시지를 복사해 고객에게 보낸다.
5. 고객이 링크를 열면 BackflowPath가 공식 출처 기반으로 다음 행동, 제출 포털, 기한, 테스터 필요 여부를 안내한다.

생성 링크는 `/notice-finder?ref={partner-code}&q={notice-clue}` 형식이다. 개인정보, 주소, 계정번호, 전화번호는 링크에 넣지 않는다.

## 2. 첫 배포 대상

7일 동안 다음 세 그룹을 동시에 수동 접촉한다.

- 백플로우 테스터 20곳: “고객에게 공지를 받았을 때 보내는 기본 링크”로 제안
- 배관·관개 업체 20곳: 작업 견적/점검 완료 후 고객 안내 링크로 제안
- HOA·부동산 관리자 20곳: 여러 세대에 같은 공지나 제출 절차를 안내하는 링크로 제안

우선순위는 기존 고객과 이미 이메일·문자·뉴스레터를 보내는 업체다. 대량 자동 발송이나 커뮤니티 도배는 하지 않는다.

## 3. 복사해서 보내는 메시지

### 테스터용

안녕하세요. 고객이 지역 백플로우 공지를 받았을 때 공식 안내와 다음 행동을 한 번에 확인할 수 있는 무료 링크를 만들었습니다. 고객별 공지 단서를 넣으면 바로 보낼 메시지가 생성됩니다: `{partner-kit-url}`

### 배관·관개 업체용

작업 후 고객에게 “이제 무엇을 제출해야 하나요?”라는 질문을 받으시면 이 무료 안내 링크를 보내보세요. 지역·공지 단서에 맞춰 제출 포털과 다음 단계를 보여줍니다: `{referral-url}`

### HOA·관리자용

백플로우 공지를 받은 소유자에게 아래 링크를 전달해 주세요. BackflowPath는 공식 출처를 기준으로 확인할 항목과 제출 경로를 정리해 주며, 공식 기관 사이트 자체는 아닙니다: `{referral-url}`

## 4. 배포 규칙

- 기존 고객에게 이미 쓰는 채널(이메일, SMS, 작업 완료 문자, 고객 포털)에만 먼저 넣는다.
- 첫 접촉은 1:1로 하고, “무료 도구를 고객에게 보내도 되는지”만 묻는다.
- 파트너가 동의하면 해당 파트너 코드로 링크를 생성한다.
- 공식 기관처럼 보이게 로고·문구를 흉내 내지 않는다.
- 규정·기한·포털은 결과 페이지의 공식 출처와 확인일을 함께 보여준다.
- 답이 없으면 3~5일 뒤 한 번만 후속 연락하고 중단한다.
- 파트너가 잘못된 정보나 링크를 발견하면 즉시 운영 큐에 기록하고 해당 조합 배포를 멈춘다.

## 5. 매일 볼 숫자

파트너별로 개인정보 없이 다음 이벤트만 확인한다.

- `partner_kit_open`: 키트 페이지를 연 횟수
- `notice_finder_search`: 파트너 링크에서 검색을 시작한 횟수
- `result_view`: 결과를 확인한 횟수
- `portal_click`: 공식 제출 포털을 연 횟수
- `share_click`: 고객·테스터·관리자에게 공유를 누른 횟수
- `request_help_start`: 해결이 안 되어 도움 요청을 시작한 횟수

첫 7일의 승자는 클릭 수가 아니라 `portal_click` 또는 `share_click`을 실제로 만든 파트너다. 3회 이상 유효 행동을 만든 조합만 후속 메시지와 내부 링크를 확장한다.

## 6. 실제 사용 검증 기록

테스터 역할로 다음 시나리오를 실행했다.

- 파트너 코드: `dallas-testers`
- 공지 단서: `Dallas SwiftComply annual notice`
- 생성 링크: `/notice-finder?ref=dallas-testers&q=Dallas+SwiftComply+annual+notice`
- 결과: Notice Finder가 같은 `ref`와 `q`를 유지하면서 실행 가능한 Dallas 경로와 다음 행동을 표시

결론: 파트너는 별도 설명이나 URL 편집 없이 공지 단서만 입력하면 고객에게 보낼 수 있다.
